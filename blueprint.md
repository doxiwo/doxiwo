
# Baseball Game Blueprint

## Overview

A simple, text-based baseball game implemented in HTML, CSS, and JavaScript. The user can "pitch" and the game will randomly determine the outcome of the at-bat.

## Design & Features

*   **Layout:** A clean, centered layout for easy interaction.
*   **Controls:** A single "Pitch" button to trigger the game action.
*   **Display:**
    *   A "scoreboard" showing the current count of balls, strikes, and outs.
    *   A message area to display the result of each pitch (e.g., "Strike!", "Ball!", "Hit!").
*   **Styling:** Minimalist styling with a focus on readability.

## Current Plan

1.  **`index.html`**: Create the basic HTML structure with a title, heading, button, and display areas.
2.  **`style.css`**: Add CSS to center the content and style the game elements.
3.  **`main.js`**: Implement the JavaScript game logic, including:
    *   Tracking game state (balls, strikes, outs).
    *   Handling the "Pitch" button click.
    *   Randomly generating pitch outcomes.
    *   Updating the game state and display based on the outcome.
